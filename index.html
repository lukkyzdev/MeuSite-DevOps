Deploy automatizado com GitHub, Jenkins e AWS S3

Olá, eu sou o Lucas Fontes. Criei este laboratório prático para eliminar uploads manuais de arquivos estáticos na nuvem, conectando os commits enviados para o GitHub diretamente ao bucket do Amazon S3 por meio de uma esteira automatizada.

Como funciona na prática

  1. Gatilho no repositório: Um commit enviado para a branch main do repositório MeuSite-DevOps dispara automaticamente um Webhook (HTTP POST).
  2. Leitura do pipeline: O Jenkins, rodando em uma instância EC2 Ubuntu, recebe o aviso e lê o Jenkinsfile diretamente do próprio repositório.
  3. Autenticação e publicação: O pipeline baixa o código atualizado, utiliza credenciais restritas do AWS IAM configuradas no cofre do Jenkins e envia o index.html para o S3 via s3Upload.

Detalhes da infraestrutura

Serviço Configuração
AWS EC2 Instância t3.micro (Ubuntu Server) executando o servidor Jenkins na porta 8080.
Amazon S3 Hospedagem estática ativada com Bucket Policy de leitura pública na região us-east-2.
AWS IAM Usuário dedicado com permissão restrita exclusivamente às operações necessárias no bucket.
FinOps Instância EC2 interrompida (Stopped) fora dos horários de teste para evitar consumo do Free Tier.
